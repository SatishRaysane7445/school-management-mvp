# School Management MVP

This is the School Management MVP (POC) — a React-based project built for NeoSoft.

## Features
- Basic student/teacher management UI
- Authentication (placeholder)
- CRUD for students, classes, and schedules
- Minimal styling and sample data for demo

## Setup (local)
1. Install Node.js (14+ or 16+ recommended)
2. Clone and install:
   git clone https://github.com/SatishRaysane7445/school-management-mvp.git
   cd school-management-mvp
   npm install
3. Start dev server:
   npm start

## Build
npm run build

## Environment
Create a `.env` or `.env.local` file for secrets (don't commit it).
